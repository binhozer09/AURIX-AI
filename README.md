# AURIX AI

Aplicativo web instalável (PWA) da AURIX AI, em português do Brasil.

## Estado atual

- Interface de conversa responsiva.
- Histórico local no navegador.
- Seleção de anexos.
- Ditado por voz quando o navegador oferece suporte.
- Estrutura PWA com cache básico.
- **O motor de IA ainda não está conectado.** A interface informa isso claramente e não simula respostas de um modelo real.

## Executar

Abra `index.html` em um servidor estático local ou publique o repositório em uma hospedagem estática compatível.

## Próxima etapa

Integrar um backend seguro e um provedor de modelo com camada gratuita/limites explícitos. Nunca colocar chaves secretas no navegador. Nenhum serviço pago deve ser ativado sem autorização do proprietário.

## Privacidade

O histórico desta versão fica no armazenamento local do navegador. Ainda não existe conta de usuário nem sincronização entre dispositivos.
